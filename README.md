# LeagueTable #

## Description ##

This project takes the results from an ice hockey tournament and produces a league table.

Results fit into different categories

### Regulation Win ###

   This is a win (scoring more goals) in regulation time (60 minutes).

### Overtime Win ###

   This is a win in overtime, or via penalty shots.

### Regulation Loss ###

   This is a loss (scoring fewer goals) in regulation time (60 minutes).

### Overtime Loss ###

   This is a loss in overtime, or via penalty shots.

Different points can be awarded to each category.
